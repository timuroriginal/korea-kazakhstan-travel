# Алматы. Своя поездка

Редакционный образец самостоятельной поездки RU/KO. Пять полных дней, отдельные прилёт/вылет, варианты города и озёр, даты и ночёвки, расходы по введённым пользователем суммам, скачивание и печать.

Это отдельная статическая страница внутри существующего сайта. Входы находятся в путеводителе и маршрутах Алматы. Другие направления не получают незавершённый продукт автоматически.

## Редактирование

- content.mjs: прибытие, первый вечер и первый полный день.
- journey.mjs: вся поездка, варианты дней и вылет.
- trip-view.js: календарь, ночёвки, выбранные дни и расчёт расходов.
- app.js / styles.css: интерфейс, настройки, скачивание и печать.
- build.mjs: собирает index.html; использует действующие авторские dayPlan из ../../assets/content-pages.js. Генерация не обращается к внешним сайтам и не проверяет факты заново.

После изменений выполнить из корня репозитория:

    node guides/almaty/build.mjs
    node tests/product.mjs

Проверка использует локальный сайт на порту 4317; KG_SITE_URL задаёт иной адрес. Артефакты теста сохраняются вне публичного репозитория. Пакет Playwright должен быть доступен в окружении проверяющего.

## Границы

На странице нет оплаты, аккаунтов, подтверждения бронирований, оператора поездки или закрытого доступа. Цена и срок доступа не определены. Отель в городе является базой примера, не обязательным участником поездки или партнёром. Дальние поездки сохраняют видимые ограничения транспорта и ночёвок. Калькулятор считает пользовательские суммы, не готовую котировку. Перед продажей нужны завершение логистики и проверка корейской редакции, фактов, коммерческого хостинга и модели доступа.

Скачанный HTML содержит тексты и функции без сети. Внешние карты и ссылки требуют подключения. Изменения сайта не обновляют ранее скачанную копию автоматически. Браузерное хранилище сохраняет настройки только на устройстве, без серверной передачи.
