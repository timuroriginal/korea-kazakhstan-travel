# Kazakhstan Guide

Корейскоязычный путеводитель по Казахстану. Текущий этап — функциональная предварительная версия с заглушками, а не проверенный туристический продукт.

## Согласовано 12 октября 2026

- Ориентир структуры: страницы направления и отдельного места по принципу japan-guide.
- Шесть направлений: Алматы, Астана, Актау, Усть-Каменогорск, Бурабай / Боровое, Туркестан.
- Голубой и золотой в духе флага РК, спокойная навигация, лёгкие эффекты без обязательной анимации.
- Фотографии и видео; сейчас явные заглушки. Национальный орнамент пока обозначен геометрическим мотивом, не копией официального флага.
- Шаблон отдельного места на примере Кок-Тобе: галерея, видео, транспорт, практическая информация, карта и местное название.
- Разработка в отдельной ветке; перенос в main и обновление основного сайта — после согласования результата пользователем.

### Уточнения структуры от владельца

- «Природа»: Алматы, Усть-Каменогорск, Бурабай. Актау убран.
- «Города»: Алматы, Астана, Туркестан. Это тематическая подборка, а не формальный перечень всех городов.
- «История и культура»: Алматы, Астана, Туркестан.
- «Еда»: Алматы, Астана, Туркестан и Актау. Для Актау отмечены темы фишбармака, рыбы и икры; места, доступность и корейские названия ещё требуют проверки.
- «У воды»: Актау и Бурабай.
- Маршруты: отдельный раздел для каждого из шести направлений, без общего акцента только на Алматы.
- «Казахстан в движении»: по одному проморолику для каждого направления. Пока шесть заглушек, реальные видео и платные генерации ещё не запускались.
- «Перед поездкой»: каждый сектор прорабатывается отдельно на следующем этапе.
- В «Маршруты» добавлен синхронный географический выбор: кнопки направлений, наведение на область/метку, нажатие на телефоне, карточка и стрелки показывают одно выбранное направление. Кнопка карточки открывает отдельный раздел его маршрутов.

### Источники карты и воспроизведение

Контуры: [UNHCR / HDX COD-AB Kazakhstan](https://data.humdata.org/dataset/cod-ab-kaz), набор `kaz_adm_unhcr_2023_SHP.zip` с 20 единицами ADM1, включая Абай, Жетысу и Улытау. Метаданные HDX сообщают о проверке в январе 2024. Лицензия: [CC BY 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/). Точки: [GeoNames](https://www.geonames.org/), лицензия CC BY 4.0; идентификаторы и исходные координаты сохранены в данных. Данные получены 12 октября 2026. Контуры преобразованы из EPSG:3857 в WGS84, упрощены для обзорной карты и спроецированы D3 7.9.0. Карта не является навигационной.

Соответствие: Алматы → город Алматы и Алматинская область; Астана → отдельная городская единица; Актау → Мангистауская область; Усть-Каменогорск → Восточно-Казахстанская область; Бурабай → Акмолинская область; Туркестан → Туркестанская область. Бурабай отмечен координатой посёлка как ориентир, а не вымышленной границей курортного района. Эти пояснения и атрибуция видны рядом с картой.

`data/map-geography.json` — преобразованная география и источники; `assets/map-data.js` — подготовленные SVG-контуры и точки; `assets/route-map.js` — интерфейс выбора. Сайт не делает внешних запросов геосервисам и не требует API-ключа. Для повторной подготовки нужен pyshp 2.3.1 и файл D3 7.9.0:

```sh
python scripts/prepare-map.py path/to/kaz_adm_unhcr_2023_shp.zip path/to/KZ.zip data/map-geography.json
node scripts/build-map.mjs path/to/d3-7.9.0.min.js
```

## Текущая реализация

Buildless HTML/CSS/JavaScript без зависимостей, серверной части, платежей и аккаунтов. Главная, шесть страниц направления, Кок-Тобе, каталог интересов, разделы подготовки, маршруты и сохранённые места.

Маршрутизация через `#/`: работает на статическом Vercel, включая прямую загрузку и обновление вложенной страницы. По умолчанию корейский; русский предназначен для проверки владельцем. Корейские названия и тексты — редакционный черновик. Сохранённые места и язык хранятся только в браузере; при запрете хранилища приложение продолжает работать.

`index.html` — оболочка; `assets/styles.css` — стили; `assets/app.js` — шаблоны и взаимодействия; `assets/catalog.js` — направления, контент и реестр медиа. `vercel.json` оставляет статическую публикацию и запрет индексации. `noindex` не является контролем доступа: URL предварительной версии может быть доступен другим людям.

## Запуск и проверка

```sh
node dev.mjs
```

Откройте `http://127.0.0.1:4317`. Другой порт: переменная `GUIDE_PORT`. Сервер предназначен только для локальной проверки.

Контрольные сценарии: все шесть направлений; переход Алматы → Кок-Тобе → назад; поиск совместно с фильтром; переключение языка на вложенной странице; сохранение и перезагрузка; галерея и диалог видео; клавиатурные вкладки транспорта; мобильное меню; неизвестный маршрут; просмотр при отключённом хранилище.

Автоматическая проверка: `node tests/browser.mjs` при установленном Playwright. Можно использовать существующий Chrome: `GUIDE_BROWSER_CHANNEL=chrome`. `GUIDE_PLAYWRIGHT_PATH` позволяет указать установленный пакет, `GUIDE_PREVIEW_URL` — адрес работающего сервера. Скриншоты сохраняются в игнорируемую папку `test-results/`.

## Наполнение

1. Тексты и локальные названия редактировать в `assets/catalog.js`.
2. Добавить лицензированные фото и реальные видео в `assets/media/`, затем заменить соответствующие `null` в реестре `media`. Примеры объектов приведены рядом с реестром. Для видео поддержаны постер, субтитры VTT и воспроизведение по нажатию без autoplay.
3. Указывать автора, источник и права. Генерированные материалы обозначать как иллюстрации; не использовать их для подтверждения реального вида места.
4. Проверить цены, расписания, транспорт, условия доступа и адреса; добавить официальные источники и дату проверки. Пока значения намеренно отсутствуют.
5. Обзорная карта направлений уже работает. Карты достопримечательностей и детальные маршруты добавлять после проверки точек; сейчас это подписанные заглушки.

## Ограничения и следующий этап

Пять направлений используют готовый шаблон без каталога достопримечательностей. Для Алматы показана только Кок-Тобе. Фото, видео, карты достопримечательностей, практические инструкции и маршруты требуют наполнения и проверки; отсутствие контента явно отмечено. Нет фиктивных оценок, отзывов, цен и подтверждённых расписаний.

После согласования предварительной версии: редактура корейского, проверка первой статьи и медиа, затем объединение ветки с main. Публичный запуск, оплата и сторонние платные генерации требуют отдельных решений. Исторические файлы проекта в `sources/` вне репозитория являются read-only reference и не редактируются этим проектом.

Главная: блок «Маршруты» использует тот же интерактивный компонент вместо шести повторяющихся текстовых карточек. Одна карточка направления, кнопки, наведение и нажатия на карте, стрелки; выбранная метка мягко подсвечена, смена карточки анимирована с учётом reduced motion. На главной пояснение о географии раскрывается по нажатию «О карте и источниках»; атрибуция остаётся видимой.
