Контуры преобразованы из EPSG:3857 в WGS84, упрощены для обзорной карты и спроецированы D3 7.9.0. Карта не является навигационной.

## Текущая реализация

Buildless HTML/CSS/JavaScript без зависимостей, серверной части, платежей и аккаунтов. Главная, шесть страниц направления, 106 страниц мест шести наполненных направлений, каталог интересов, разделы подготовки, маршруты и сохранённые места.

Корейские названия и тексты — редакционный черновик. Сохранённые места и язык хранятся только в браузере; при запрете хранилища приложение продолжает работать.

`index.html` — оболочка; `assets/styles.css` — стили; `assets/app.js` — шаблоны и взаимодействия; `assets/catalog.js` — направления, контент и реестр медиа. `vercel.json` оставляет статическую публикацию и запрет индексации. `noindex` не является контролем доступа: URL предварительной версии может быть доступен другим людям.
